## Project Output

The system successfully demonstrates intelligent traffic signal control based on traffic density and emergency vehicle detection.

### Normal Traffic Mode
- Traffic density is detected on each lane.
- Signal timing is adjusted according to traffic density.
- The lane with higher traffic receives longer GREEN time.

### Emergency Vehicle Mode
- Emergency vehicle is detected.
- The corresponding lane receives a GREEN signal.
- Other lanes receive RED signals.
- The emergency vehicle gets a clear path through the junction.
- After the vehicle passes, the system automatically returns to normal traffic operation.

### Final Output

The prototype successfully provides dynamic traffic management and emergency vehicle priority, helping to reduce traffic congestion and emergency response time.
