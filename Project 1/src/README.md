# Source Code

This folder contains the main C++ source code for the Smart Traffic Signal & Emergency Vehicle Priority System.

## File

`smart_traffic_signal.cpp`

## Implementation

The program implements:

- Circular Linked List for continuous traffic signal management.
- Doubly Linked List for road and junction management.
- Traffic signal insertion and deletion.
- Road junction insertion and deletion.
- Forward and backward traversal.
- Emergency vehicle priority.
- Normal traffic signal cycle restoration.

## Data Structures

**Circular Linked List:** Used for the continuous traffic signal cycle.

**Doubly Linked List:** Used for the road network and two-way junction traversal.

## Language

C++

## Execution

Compile the source file using a C++ compiler and run the generated executable.
